Mode d'emploi

Cet outil vous donne accès à une intelligence artificielle qui tourne sur votre ordinateur, sans envoyer vos données à un serveur extérieur. Les modèles utilisés sont libres et gratuits, mis à disposition par Meta, Mistral AI (Paris), Microsoft, Google ou Alibaba.

1. Installer · 2. Choisir son modèle · 3. Vérifier que c'est local · 4. Limites à connaître · 5. Matériel

Ce qui est garanti, et que vous pouvez vérifier vous-même :
  • En mode local (le mode par défaut), aucune donnée n'est envoyée à un serveur extérieur (preuves dans la section 3). Seul le mode cloud OpenRouter, que vous devez activer vous-même, envoie vos textes à un tiers.
  • Aucun compte, aucun cookie, aucun traceur publicitaire.
  • Tous les modèles proposés sont publiés sous licence libre par leurs éditeurs.
  • Le code d'IA Locale est public sur GitHub (licence MIT), comme celui du moteur Ollama — n'importe qui peut les relire.
  • Cet outil fonctionne même sans connexion Internet une fois installé.

1. Installation

⚡ Méthode simple : un double-clic

  1. Si Ollama n'est pas installé sur votre ordinateur : téléchargez-le sur ollama.com/download et lancez l'installeur. (Une seule fois dans votre vie.)
  2. Double-cliquez sur le lanceur :
    • Mac : IA Locale.app (à glisser dans Applications)
    • Windows : IA Locale.bat (dans le dossier IA Locale) — ou le raccourci créé par Installer le raccourci bureau.bat
    Le lanceur démarre Ollama, installe un premier modèle si nécessaire (Ministral 3, environ 3 Go), et ouvre cette page avec la pastille verte en haut à droite. Il ne modifie aucun réglage d'Ollama.

Au tout premier lancement : sur Mac, si macOS refuse d'ouvrir l'application (« Apple ne peut pas vérifier… »), ouvrez Réglages Système → Confidentialité et sécurité, descendez jusqu'au message sur « IA Locale » et cliquez sur Ouvrir quand même (sur macOS 14 et plus ancien : clic droit sur l'app → Ouvrir). Sur Windows, SmartScreen peut afficher un avertissement : Informations complémentaires → Exécuter quand même. C'est normal : l'application n'est pas signée par un certificat payant ; son code est lisible sur GitHub.

2. Choisir son modèle d'IA

Le modèle est le « cerveau » de l'IA. Il se télécharge une fois, puis fonctionne hors ligne sur votre machine. Tous les modèles ci-dessous sont gratuits et publiés sous licence libre par leurs éditeurs. Vous pouvez en installer plusieurs et passer de l'un à l'autre.

Pour en installer un : onglet Modèles, bouton Installer. Plus besoin du Terminal.

Catalogue vérifié le 4 octobre 2026 dans la bibliothèque officielle d'Ollama. Les modèles marqués « images » savent lire une photo ou un schéma.

Détail de chaque modèle

Si vous débutez : ministral-3:3b (français, 8 Go de mémoire suffisent). Avec 16 Go : ministral-3:8b. Machine très ancienne : llama3.2:3b.

3. Comment vérifier que c'est vraiment local ?

Cette section liste trois vérifications indépendantes que n'importe quel enseignant peut faire, sans compétence technique particulière, pour s'assurer que ses données ne sortent pas de la machine. Vous n'avez pas à nous croire sur parole.

✈️ Test n°1 : couper Internet

Coupez le Wi-Fi (ou activez le « Mode Avion »). Posez une question dans le Chat. Si la réponse arrive normalement, c'est qu'aucun serveur extérieur n'est sollicité. C'est la preuve la plus simple et la plus parlante.

🔍 Test n°2 : Moniteur d'activité

Ouvrez le Moniteur d'activité (Mac) ou le Gestionnaire des tâches (Windows) pendant qu'une réponse est en cours. Vous verrez le processus ollama consommer du CPU et de la RAM, sans pic notable de trafic réseau.

📡 Test n°3 : observer les connexions

Pour les plus curieux : dans le Terminal, tapez lsof -i -P | grep ollama (Mac) ou utilisez Resource Monitor (Windows). Vous verrez uniquement des connexions locales (localhost / 127.0.0.1), aucune sortie vers Internet.

🔓 Test n°4 : lire le code source

Ollama est publié sur GitHub sous licence MIT. Le code complet est lisible publiquement. La même page HTML que vous utilisez est également un fichier texte — clic droit → « Afficher la source » pour la lire.

Nuance honnête : Ollama vérifie au démarrage si une nouvelle version est disponible (ping unique vers leur serveur de mises à jour). Cela n'envoie aucun contenu de conversation, juste le numéro de version. Si vous voulez couper même cela : désactivez Internet ou bloquez les sorties d'Ollama dans votre pare-feu.

4. Ce que ces modèles savent (et ne savent pas) faire

✅ Ils sont bons à

  • Rédiger des plans de séquence, des consignes, des QCM, des fiches.
  • Reformuler, simplifier, expliquer un concept à différents niveaux.
  • Donner un premier feedback structuré sur une production écrite.
  • Proposer des activités, des mises en situation, des questions de relance.
  • Traduire, résumer, comparer des contenus.

⚠️ Ils ne savent pas (ou mal)

  • Connaître l'actualité récente. Leur connaissance s'arrête à leur date d'entraînement (2023-2024 selon les modèles). Ne leur demandez pas qui a gagné les élections de l'an dernier.
  • Garantir l'exactitude. Les IA génératives peuvent halluciner : inventer une citation, une date, un nom d'auteur, une source plausible mais fausse. Toute information factuelle doit être vérifiée par vous avant usage en classe.
  • Calculer parfaitement. Sur l'arithmétique complexe ou les formules, ils peuvent se tromper. Utilisez une calculatrice pour vérifier.
  • Citer des sources fiables. S'ils mentionnent un livre, un article ou un chiffre, vérifiez l'existence réelle avant de l'utiliser.
  • Évaluer une copie à votre place. Ils peuvent proposer des pistes de retour ; la note et le jugement pédagogique restent votre prérogative (rappel du cadre d'usage EN, juin 2025).

💡 La bonne posture

Considérez ces modèles comme un stagiaire compétent mais à relire. Ils dégrossissent un travail rapidement, mais ne remplacent ni votre expertise disciplinaire, ni votre connaissance de vos élèves, ni votre responsabilité d'enseignant. Ils sont des outils — utiles, gratuits, respectueux de la vie privée — pas des oracles.

5. Configuration matérielle

Minimum : 8 Go de RAM, processeur des 5 dernières années. → ministral-3:3b, qwen3.5:4b, granite4.2:3b ou llama3.2:3b.

Confortable : 16 Go de RAM. → ministral-3:8b, gemma4:e4b, qwen3.5:9b fonctionnent fluidement.

Idéal : Mac Apple Silicon (M1 à M5) ou PC avec carte graphique dédiée. → Avec 24 à 32 Go : gpt-oss:20b ou mistral-small3.2:24b.

Astuce : si une réponse met plus de 30 secondes à arriver, votre machine est probablement à la limite — passez sur un modèle plus petit. La vitesse dépend surtout de la RAM et du GPU.

Pas de matériel suffisant ? Vous pouvez activer une clé OpenRouter optionnelle pour utiliser des modèles gratuits dans le cloud. ⚠️ Dans ce cas, les textes saisis transitent par un serveur tiers : n'envoyez aucune donnée personnelle d'élève et utilisez l'anonymisation automatique.

Conformité — ce que dit la réglementation

Cet outil est conçu pour respecter par défaut le cadre d'usage de l'IA en éducation publié par le Ministère de l'Éducation nationale (juin 2025) et les recommandations de la CNIL.

✅ Ce qui est garanti en mode local (Ollama)

  • Aucune donnée n'est envoyée sur Internet.
  • Aucun compte n'est créé, aucun cookie, aucun traceur publicitaire.
  • Vos conversations restent dans le navigateur (localStorage) — supprimables à tout moment.
  • Les modèles utilisés sont open-source (Llama, Mistral, Phi, Qwen…).

Les 5 principes du cadre d'usage Éducation nationale (juin 2025)

1. Plus-value pédagogique

L'IA doit apporter un bénéfice réel à l'apprentissage, pas juste être utilisée pour l'effet « wow ».

2. Protection des données

Vigilance accrue avec les outils grand public. Le mode local de cette page résout cette question.

3. Conscience environnementale

L'IA générative consomme de l'énergie. Privilégier les modèles légers (3B-8B) pour les usages courants.

4. Transparence

Indiquer quand un contenu a été produit avec une IA, en classe comme dans vos préparations.

5. Esprit critique

Toute production de l'IA doit être relue, vérifiée, corrigée. Elle peut se tromper, inventer des sources, présenter des biais.

Recommandations CNIL pour les enseignants

  • Pas de compte individuel élève quand c'est évitable. Si nécessaire, privilégier un compte « classe ».
  • Pas de réutilisation des données par l'outil pour entraîner ses modèles.
  • Pas d'élément de vie privée de l'élève (santé, famille, opinions…) saisi dans un outil d'IA.
  • L'évaluation reste de votre responsabilité. L'IA peut aider à formuler un retour, mais la note et la décision sont votre prérogative pédagogique.
  • Sensibiliser les élèves à la protection de leurs données dans l'usage des outils numériques.

Règles pour les élèves (cadre EN juin 2025)

  • L'usage de l'IA générative par les élèves en classe est autorisé à partir de la 4ᵉ, et doit être limité, encadré, expliqué.
  • Tout recours à l'IA pour réaliser un devoir sans autorisation explicite et sans appropriation personnelle est considéré comme une fraude.
  • Une micro-formation Pix dédiée est obligatoire pour les 4ᵉ et 2ᵈᵉ depuis la rentrée 2025.

Anonymisation

Quand l'option est activée dans le chat, l'outil remplace les prénoms et noms de famille repérés par Élève A, B, C… (et les adultes cités avec Mme, M.… par Personne A…) avant l'envoi au modèle — pour toute la conversation. Indispensable en mode cloud ; utile aussi en local.

La liste intégrée compte environ 500 prénoms courants, et les personnalités souvent étudiées (Victor Hugo, Marie Curie…) ne sont jamais masquées. L'anonymisation est une aide : relisez ce que vous envoyez.
